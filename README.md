## 双 ISP 到底是什么，下单后怎么自己验

双 ISP 说的是 IP 在数据库里的两个字段同时显示为 ISP：ASN（自治系统号）归运营商，Company（公司归属）也是运营商，而不是 Hosting 或 Datacenter。普通机房 IP 查出来是 Hosting 类型，归属写的是云厂商，平台风控一眼就能分辨。还有个词叫广播 IP，是把机房 IP 通过技术手段伪装成住宅 IP，风控系统有概率识别出来，这类 IP 便宜的居多。

验一套 IP，三步够了。

第一步，打开 ipinfo.io 查这个 IP，type 字段应该是 `isp`，ASN 和 Company 都指向运营商。第二步，去 scamalytics.com 看欺诈分，低于 30% 算优秀，低于 50% 还能用。第三步，拿你的目标平台实测：TikTok 注册页能不能过、Netflix 能不能播美区全库、ChatGPT 登不登得上。三步都过，再谈续费。

这里有个容易被忽略的地方：不同 IP 数据库的标准不一样，一个说家宽、另一个可能判机房。上个月 vps55 那篇六六云美国 AS4837 的测评里，作者查 IP 的结果就是“多个数据库识别是家宽 IP，但 IP2Location 判断是 IDC 机房 IP”，风险分多数数据库显示低风险、黑名单 0 条。这种情况不算翻车，但说明它不是一个 100% 纯血住宅 IP。买之前心里要有数，业务对 IP 类型卡得越死，越要自己上手验。

第三条在带宽的理解上。1Gbps 是端口上限，不代表你从国内能跑出 1Gbps。vuidc 那篇测评里作者本地下载 10.8MB/s，他自己也说明这是跨太平洋的实际速度，受国际出口限制，跑不满是正常的。家宽 VPS 的带宽普遍在 30 到 200Mbps 之间，标注的多数是共享带宽或端口上限，要独享带宽得看 AaIT 这类明确写独享的产品。

第四条是延迟。家宽走的是住宅网络基础设施，延迟普遍 170 到 250ms，比优化线路的机房 VPS 高。对延迟极敏感的场景（远程桌面、视频会议、实时语音），配个香港中转能压到 80 到 120ms，日本中转 100 到 140ms，代价是多一跳、多一份成本。
